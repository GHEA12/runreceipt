RunReceipt — verify an agent run

Paste a run log and its anchored copy. This page recomputes every SHA-256 hash locally in your browser and compares — if a single byte was altered after anchoring, verification fails. Nothing is uploaded anywhere.

RunReceipt by Indra Dwi Junianto. Verification logic: canonical JSON (sorted keys) + SHA-256 via the browser's SubtleCrypto — the same algorithm as the reference Node implementation in src/canonical.js / src/verify.js.
